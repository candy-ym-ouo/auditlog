# 防篡改审计日志服务（AuditChain Guard）

> 基于 Go 语言实现的防篡改审计日志服务：使用**哈希链（Hash Chain）**保存关键操作记录，支持**完整性验证、后台归档、操作追溯**；持久化记录并管理**数据库迁移**，对外提供 **REST API** 与**简单前端界面**，配套完整的**单元/集成测试**与**一键完整验证**能力。

---

## 1. 项目定位

本服务解决"关键操作记录一旦落库就可能被静默篡改"的信任问题。它把每一条审计记录通过密码学哈希串联成一条**不可逆的链**：

- 任何一条历史记录被修改，都会导致其自身哈希失配，并沿着链条向后扩散，使**篡改行为可被检测**；
- 验证、归档、追溯、迁移全部围绕这条链展开，保证"写入可审计、历史可验证、记录可追溯、数据可迁移"。

## 2. 核心特性

| 特性 | 说明 |
| --- | --- |
| 哈希链存储 | 每条记录携带 `prev_hash` 与自身 `hash`，SHA-256 串行成链，含创世条目 |
| 完整性验证 | 支持全链验证 / 区间验证 / 链头验证 / 抽样验证，输出结构化验证报告 |
| 后台归档 | 定时 + 手动归档旧记录，归档批次带清单（manifest）与批次哈希，不破坏链 |
| 操作追溯 | 按操作人 / 动作 / 目标对象 / 时间范围查询，支持单条上下文回溯与报告导出 |
| 持久化与迁移 | SQLite 单文件存储（WAL 模式），内置版本化迁移器，启动自动迁移 |
| REST API | 标准 JSON API：写入、查询、验证、归档、追溯、统计、健康检查 |
| 简单前端 | 原生 HTML/CSS/JS 单页界面，经 `embed` 由 Go 服务直接托管 |
| 测试与完整验证 | 分层测试（单元 + 集成 + 端到端验证脚本）与一键"完整验证"命令 |

## 3. 技术栈

- 语言：Go 1.21+
- HTTP：标准库 `net/http`（自定义轻量路由，无第三方框架依赖）
- 存储：SQLite（纯 Go 驱动 `modernc.org/sqlite`），WAL 模式，单文件
- 前端：原生 HTML5 + CSS3 + JavaScript（无构建工具、无框架）
- 静态资源：`embed.FS` 内嵌前端，单一二进制部署

## 6. 运行与打包

项目代码已按照设计文档实现，服务入口为 `cmd/server`，前端静态资源由 Go `embed` 打包进单一可执行文件。

```bash
go test ./...
go build -o auditlog-server ./cmd/server
./auditlog-server -db ./audit.db -addr 127.0.0.1:8080
```

启动后访问 `http://127.0.0.1:8080`。评测容器打包文件和多架构构建命令见 [BENZHI_README.md](BENZHI_README.md)。
